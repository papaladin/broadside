⚓ Broadside — Return Coverage (Pass 1)

Static AST return-point counting + runtime return-shape fingerprinting. Zero source edits.
What this measures: for every exported function in logic.js / generators.js, and every action case in the engine reducers, this tool statically counts how many distinct return points exist (via a real AST parse — not a text guess), then runs the full test suite and records how many distinct return shapes were actually observed at runtime.

Honest limitation: two different branches that both return an unchanged/no-op value in the same shape (e.g. two different blocked-conditions that both return state;) will fingerprint identically and appear as one observed shape even though they're two separate code paths. Rows flagged collision risk have this ambiguity — the static analysis lists the exact lines involved so you can decide whether to add a one-line disambiguation mark there. Everything else is exact.
